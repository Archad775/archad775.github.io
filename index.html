Olist Marketplace Truth Layer

100,000+ orders from Brazil's largest e-commerce marketplace, built into a production-grade analytics pipeline. The real work isn't the dashboard — it's what's underneath it: a fully tested, documented dbt project with bronze → silver → gold data layers, 32 automated data quality tests, and clean dimensional models where every metric is auditable back to its source row. The dashboard is proof the foundation holds.

dbt pipeline: raw CSV ingestion through bronze, silver and gold layers, fully documented with schema.yml and column-level descriptions
32 automated data tests (25 pass, 7 warnings) surfacing real issues: 1,359 carrier approvals before shipment, missing freight values, approval gaps
11.5% 1-star rate, 26% of late orders still rated 4–5 stars, top 10% of sellers control 67.6% of GMV

ShopStream Revenue Intelligence

Revenue was climbing. Gross margin was quietly shrinking. ShopStream's numbers looked healthy until you built the pipeline that could see underneath them. Raw exports → Python ingestion → PostgreSQL → Dagster orchestration → Power BI, fully automated with GitHub Actions pushing fresh data without a single manual run. The dashboard doesn't just track revenue — it tracks where it leaks.

6.29M revenue, 44.4% gross margin across 4 categories and 4 regions, with margin eroding despite volume growth
Dagster pipeline fully automated: ingests, transforms and loads on schedule, pushes updated exports to GitHub with no manual intervention
Category-level profitability breakdown reveals which products grow the top line while quietly destroying the bottom line
